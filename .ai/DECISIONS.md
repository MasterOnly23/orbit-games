# Durable decisions

## DEC-001 — Independent Next
Separate checkout, app ID, profile and packaging protect the user's active Orbit. All development and QA remain in Next; no implicit migration or stable installation replacement.

## DEC-002 — Local-first connectors
Use official APIs or maintained community implementations when viable, disclosing limits. Avoid owned servers; raise any essential server requirement explicitly. Keep authentication in isolated main-process sessions; persist only permitted metadata and protected credentials where required.

## DEC-003 — Evidence-based library
Account access and local installation are independent. Exact provider identities may join records; names cannot supply missing identity. Preserve personal edits. Ambiguity remains separate until resolved; no destructive historical duplicate repair in an identity increment.

## DEC-004 — Public readiness gates
Windows 10 and 11 x64 are both first-launch requirements. Fixtures, source builds and existing alpha packages have distinct evidence. Root roadmap gates remain open until their complete acceptance conditions pass.

## DEC-005 — Orchestration (2026-10-01)
User objective now requests Astra architecture/review and Luna Max implementation, with Sol Low escalation only for difficult work. Tasks have bounded file ownership and verification; `.ai` holds current operational context, root roadmap holds product scope.
